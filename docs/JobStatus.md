# JobStatus

Terminal-state enum for a job, grounded one-for-one in the store states. `pending` is the only non-terminal state (parked, awaiting operator approval). 

## Enum

* `PENDING` (value: `'pending'`)

* `SETTLED` (value: `'settled'`)

* `DENIED` (value: `'denied'`)

* `FAILED` (value: `'failed'`)
